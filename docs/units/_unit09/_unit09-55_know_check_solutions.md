## 3️⃣ Multiple Choice

Assume:

```python
class Animal:
    def sleep(self):
        print("Sleeping")
```

What is the name of the method defined in this class?

A) Animal

B) self

C) sleep ✅

D) print

**Correct answer:** C

## 4️⃣ Multiple Choice

```python

```

A) Bird inherits from Animal ✅

B) Animal inherits from Bird

C) Bird is a list

D) The code contains an error

**Correct answer:** A
